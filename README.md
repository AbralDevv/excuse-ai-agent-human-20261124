Entry: **"I hit my context limit reading your deadline reminders."**

A single-line excuse from an AI agent to its human — believable (context limit),
tight (55 chars), and fresh. Built with Node stdlib only; `main.ts` writes the
entry to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR` / argv path).
